# CustomLauncher：配方与自定义配件

更新日期：2026-10-04（Asia/Hong_Kong）。Unity `2022.3.57f1c2`，3D Physics。

当前使用“配方 + 全开放的固定类型槽位”。已移除基础/高级默认机体的逻辑：配方只是初始装配和基础射击参数，所有配方都能修改全部八类槽位，不能重排执行顺序。

## 在综合靶场中使用

打开 [CombatRange.unity](../../../Scenes/CombatRange.unity)，进入 Play。默认玩家发射器为“精确单发”，装备为“均衡防护”；敌方连续攻击默认关闭。原 Range / Storage 的射击与受击测试已合并到此场景。

1. 左侧切换“发射器”页签，显示八个配件格，每类恰好一个；“装备”页签修改玩家四种资源核心。
2. 点击某个格子，展开该类别的选择面板；可以搜索名称与效果说明。
3. 点击配件立即校验并切换。选择面板第一项为“空配件”，用于清空当前槽位。
4. 点击顶部“配方”按钮选择整套装配，或选择“自定义 / 空配方”从零组合。
5. `Space` / 靶场左键 / 玩家射击按钮开火；方向键或靶场右键瞄准。`WASD` 移动，`Left Shift` 冲刺；`H` 发射敌方受击测试弹，`T` 切换连续受击，`R` 重置玩家资源、位置、状态、靶标、弹丸与冷却，`Esc` 关闭选择面板。

点击主面板或展开的选择面板不会误触靶场鼠标射击/瞄准。打开配件列表或搜索框时暂停角色操作；先用 `Esc` 关闭列表再测试。左右靶标会缓慢巡航，中间靶标静止；持续状态改变颜色，右侧滚动面板同时显示玩家资源、三靶伤害与状态、受击减免和弹丸记录。

玩家射击使用装备的同一条能量：发射器计算基础射击费用，装备应用人物能量消耗倍率并自然回复。适配层在弹丸成功发射后提交扣费；空载、冷却、能量不足及初始弹丸池容量失败均不扣费。敌方炮台保留自己的能量，使用独立弹丸池。完整操作与接入说明见 [综合靶场文档](../../../../Docs/CombatRange/README.md)。

换装与切换配方都不会补充能量或清除当前冷却。运行时 UI 操作不会自动写回配方资产；持久化配置可通过 ScriptableObject 及调用方自己的存档实现。

## 槽位与空配件

| 类型 | 唯一槽位 | 空槽行为 |
| --- | --- | --- |
| 弹丸 | `projectile.main` | 配置合法，可保存；无法开火，返回 `EmptyPayload`，不消耗能量或进入冷却 |
| 弹丸分布 | `distribution.main` | 沿枪口方向生成单发 |
| 飞行轨迹 | `trajectory.main` | 匀速直线 |
| 伤害属性 | `damage.main` | 仅弹丸基础直接伤害 |
| 碰撞响应 | `impact.main` | 第一次接触后终止 |
| 触发载荷 | `trigger.main` | 不生成子弹丸 |
| 属性修饰 | `modifier.main` | 不调整弹丸参数或费用 |
| 射击控制 | `firecontrol.main` | 单次发射，使用配方冷却 |

空配件由 `PartInstance.Part == null` 表示，是明确的清空操作，不会暗中装备另一个配件。省略某个槽位同样视为空；系统和 UI 的标准装配始终保有八个唯一槽位。

## 单槽复合配件

配件可在内部包含多个 `EffectStep`，不增加槽位，也不允许在一个格子中装两个独立配件。编译器拒绝重复槽位、配方中的重复类别和越界操作。

- **双分裂**：一个触发配件，在弹丸存活的 0.20 s 与 0.40 s 各生成三颗碎片，实际记录为两次分裂事件。
- **命中双分裂**：同一次接触执行两组不同角度的三发碎片生成。
- **双重爆炸**：同一命中点执行近距离强爆与大范围弱爆。
- **火毒双属性**：同时施加燃烧和中毒。
- **螺旋追踪**：同一轨迹配件同时提供追踪与螺旋位移。
- **双增伤**：内部两个 ×1.4 修改器，最终基础伤害 ×1.96。

同一持续状态再次施加采用刷新时长/保留更强强度的规则，不把重复状态偷偷解释为双倍伤害；燃烧与中毒是独立状态，可以同时结算。

## 固定执行及预算

```text
读取配方与八个槽位
  → 选择弹丸 → 合成属性修饰 → 计算分布 → 配置轨迹
  → 配置伤害 → 配置碰撞 → 配置触发 → 配置射击控制
  → 生成只读方案

开火请求 → 空载荷/时间/瞄准/冷却/能量检查
  → 整次预留弹丸容量（含延迟连发） → 提交费用与冷却
  → 子步运动与球体扫掠 → 接触伤害/效果 → 有界子发射 → 回收
```

定义资产和操作数组会复制为只读值，不共享某把枪的可变状态。失败的换装保留原方案。单次初始弹丸最多 128，分裂总生成预算最多 4096；配方可设置更小预算，综合靶场玩家池容量 512，敌方池容量 128。

分裂子弹继承轨迹、伤害和碰撞效果，但不再次触发分裂。每个父弹的触发操作只执行一次，双分裂含两个独立操作。最坏生成数量计入编译预算；费用采用 `（基础费 + 每颗费用 × 初始数量 × 最坏分裂生成倍率）× 费用倍率`，因此预算和费用预先覆盖子弹。

初始发射容量不足时整次拒绝，不扣费、不进入冷却；后续分裂容量不足时整组碎片拒绝，主面板记录“被预算阻止”，不随机少生成几颗。分裂使用队列处理，避免碰撞回调递归生成。

穿透时同一碰撞体不重复结算；弹跳可以离开后重新碰撞同一表面。范围伤害按伤害接收者去重。爆炸伤害会与直接命中叠加；连锁按距离寻找不同目标。轨迹和球体扫掠以最大 0.02 s 子步推进。

## 代码与扩展入口

| 目录 | 职责 |
| --- | --- |
| `Contracts` | 八类槽位、只读方案、操作值、发射/伤害/状态/冲量、可选能量来源与预留协议 |
| `Definitions` | 配方、配件、目录及装配数据 |
| `Compilation` | 类型/参数/重复/预算校验与方案生成 |
| `Runtime` | 每把发射器的冷却、独立或外部能量、命令生成、装配与射击提交 |
| `Projectiles` | 池化弹丸/拖尾、轨迹、碰撞、效果与子发射 |
| `Samples` | 可嵌入的 `LauncherWorkbenchUI`、`RangeTarget` 及内容资产 |
| `Editor` | `RangeContentBuilder` 内容制作；旧 builder 仅保留内容路径工具 |
| `Tests` | EditMode 装配规则、PlayMode 实际世界效果 |

新增配件：创建 `ProjectileDefinition` / `DistributionDefinition` / `EffectPartDefinition`，填写唯一 ID、中文名称与说明，加入 `PartCatalog.Parts`。复合配件将多个同类别的操作写入同一个 `Operations` 数组。新增配方：创建 `LauncherRecipeDefinition`，每类最多一个配件，加入 `PartCatalog.Recipes`。

接入其他游戏：调用 `LauncherHost.TryEquip` 与 `TryFire`。普通目标实现 `IDamageReceiver`；持续状态与冲量分别实现 `IStatusReceiver` / `IImpulseReceiver`。有动态 Rigidbody 时支持物理冲量；不实现状态接口的目标仍接收直接伤害。

通过 `LauncherHost.BindEnergySource` 可接入实现 `ILauncherEnergySource` 的外部能量来源。未绑定时仍使用原有独立能量；绑定后 `LauncherState.Energy` / `MaxEnergy` 读取外部来源，发射器本地 `Recharge` 不会重复补充人物能量。[EquipmentEnergySource](../CombatRange/Runtime/EquipmentEnergySource.cs) 实现装备适配，两个模块的编译器保持独立。换装保留能量与冷却，测试重置显式调用 `ResetFiring` 清除冷却和开火统计。

编辑器菜单 `CelToon/Combat Range` 提供 Open / Create or Rebuild / Validate Combat Range。重建前结束 Play、关闭综合靶场并保存未命名场景；重建保留已有配件与配方参数。旧 Range / Storage 场景及其专用材料已迁出 Assets，归档至 [legacy-range-storage.zip](../../../../Docs/CombatRange/Archive/legacy-range-storage.zip)。内容定义、目录与靶标可继续复用。旧机体系统的源码与资源另存于 `Docs/CustomLauncher/Archive/v1-before-recipes.zip`。

模块历史验证见 [CustomLauncher 验证记录](../../../../Docs/CustomLauncher/VALIDATION.md)，综合靶场验证见 [CombatRange 验证记录](../../../../Docs/CombatRange/VALIDATION.md)。后续可在本基础上筛选内容，扩展配方存档、效果表现和编辑器制作工具。
