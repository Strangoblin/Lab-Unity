# CustomEquipment：玩家装备与自定义配件

更新：2026-10-04（Asia/Hong_Kong），Unity 2022.3.57f1c2，3D Physics。

沿用同级 CustomLauncher 的流程：**配方 → 四种资源核心 → 编译校验 → 只读方案 → 每个玩家独立状态**。生命、护盾、体力、能量分别对应一件装备。配件将资源上限保存为 `PrimaryOperations`，其他加成保存为固定副词条 `Affixes`；不能在同类槽位叠装多个独立配件。清空核心会移除其主属性与全部副词条。

## 综合靶场使用

打开 [CombatRange.unity](../../../Scenes/CombatRange.unity)，进入 Play。默认装备“均衡防护”，玩家发射器为“精确单发”，敌方连续攻击默认关闭。射击、受击和双系统自定义统一在此场景测试。

修改脚本后若仍出现旧版本报错，先退出 Play，执行 `Assets > Refresh`（Ctrl+R），等待编译结束后再进入 Play。配件按钮与快捷键在 Play 中生效；非 Play 的 Game View 只显示场景预览。

- 左侧切换“装备”页签，点击生命、护盾、体力、能量核心，打开对应中文配件列表；支持搜索名称与说明，第一项是“空配件”。顶部配方按钮可选择整套装配，包括“自定义 / 空配方”。“发射器”页签提供全部八类发射器配件。
- 右侧用 ◀ / ▶ 切换八种测试攻击，发射真实 CustomLauncher 弹丸，也可直接施加 25 点伤害。
- 右侧显示生命、护盾、体力、能量四条资源，以及基础射击费用、装备消耗倍率、实际费用和能量回复。玩家真实射击直接消耗此能量；敌方炮台使用独立能量与弹丸池。
- `WASD` 移动，`Left Shift` 冲刺，方向键或靶场右键瞄准；`Space` / 靶场左键为玩家射击，`H` 发射敌方测试弹，`T` 切换连续受击，`R` 重置资源、位置、状态、两边弹丸、靶标统计与射击冷却，`Esc` 关闭选择面板。
- 键盘事件由综合靶场统一接收；先点击 Game View 使其获得键盘焦点。打开选择面板时使用 Esc 关闭后再操作角色，搜索框中的输入不会误触开火、重置或连续攻击。Space 不会同时激活上次聚焦的按钮。
- 右侧滚动面板显示实际移速、状态剩余时间、最近伤害分解、累计减免、应急触发及三靶射击记录。玩家四种核心显示彩色几何标记；受击、燃烧、中毒、倒下会改变本体颜色。完整说明见 [综合靶场文档](../../../../Docs/CombatRange/README.md)。

换装与切配方**保留当前生命、护盾、体力、能量、持续状态及所有运行计时**，只在新上限较小时钳制数值。提高上限不会补满资源；可等待回复或使用显式测试重置。首次装配从满资源开始。玩家倒下后停止移动、恢复、能量消耗与自动攻击，按 R 重新测试。运行时换装不修改 ScriptableObject 资产，不自动保存到磁盘。

## 四类核心槽位

| 类型 | 槽位 | 主属性 |
| --- | --- | --- |
| 生命核心 | `healthcore.main` | 生命上限加法与倍率 |
| 护盾核心 | `shieldcore.main` | 护盾上限 |
| 体力核心 | `staminacore.main` | 体力上限 |
| 能量核心 | `energycore.main` | 能量上限 |

护甲、伤害减免、抗性、生命/护盾/体力/能量回复、回复等待、移动与冲刺、受击保护、急救、净化和消耗倍率均为固定副词条，可放在任一种资源核心上。副词条不承载任何资源上限；编译器分别校验主属性归属与副词条内容。当前未实现随机生成或副词条稀有度/预算平衡。

所有空槽都不添加效果；全空装配仍具有配方声明的本体属性。标准本体为生命 100、护盾 0、体力 100、能量 100；体力回复 15/s、冲刺消耗 22/s、能量回复 10/s、能量消耗倍率 1。步行 3 m/s、冲刺倍率 1.7，不自带护甲、抗性或生命回复。

当前选择目录为 **16 个核心配件（每槽 4 个）、10 个装备配方、8 种攻击配置**。配件清单见 [PARTS.md](PARTS.md)。攻击包括标准动能、重击与击退、燃烧、中毒、寒霜减速、震击眩晕、易伤标记、火毒复合弹。

### 旧装配兼容

旧八槽和上一版防御/护盾/机动/应急四核心均可迁移。生命、护甲、抗性、恢复、受击反应和净化归入生命核心；护盾归入护盾核心；移动与体力归入体力核心。各核心按操作拆为主属性与副词条，旧的纯副词条核心补入 +0 主属性，保留原有效果。旧配方新增标准基础能量，能量槽为空时仍有基础能量，可主动选择新的能量核心。

迁移保留原有基础属性和操作参数，在 `MigratedCores` 下生成稳定兼容资产；不删除旧枚举编号、配件或引用。单核心最多 65 项操作、整套装配最多 68 项，允许旧 64 项纯副词条组合补入中性主属性。配方的 `ResourceSchemaVersion` 标记能量初始化已完成，避免将主动配置的零能量容量误当作旧字段缺失。

已有配方显示“兼容·…”核心时，参数仍为原来的组合；**替换或清空核心会移除该组全部效果**。新目录的核心可能具有不同数值，选择它属于主动换装。四槽布局为 2×2，卡片显示资源主属性与副词条数量。迁移前备份：[八槽版](../../../../Docs/CustomEquipment/Archive/v1-eight-slots.zip)、[上一版四核心](../../../../Docs/CustomEquipment/Archive/v2-four-cores.zip)。

### 能量与发射器边界

人物能量由 `EquipmentState` 管理，`TrySpendEnergy(baseCost)` 按人物消耗倍率扣除，余额不足/无效成本/倒下时原子拒绝；`RechargeEnergy(amount)` 与 `Tick` 分别提供显式和自然回复。装备编译只计算人物资源与加成，不读取发射器配方或发射状态。

综合靶场已通过独立的 `EquipmentEnergySource` 将玩家 `LauncherHost` 绑定到此人物能量来源。发射器提供基础费用，装备负责应用人物消耗倍率；适配层预留能量，真实弹丸初始发射成功后提交，容量失败时回滚。空载、冷却、无效瞄准、能量不足和倒下均不会消耗能量。`LauncherState.Energy` 与人物能量条读取同一份数据，人物回复和换装后的上限钳制也立即同步。

未绑定外部来源的发射器继续使用独立能量，敌方炮台采用此模式。玩家与敌方弹丸池分别为 512 / 128，避免受击测试占用玩家初始发射容量。共享能量的接口属于 CustomLauncher.Contracts，装备编译器与运行状态不读取发射器计划，具体适配及场景输入属于 CombatRange。

## 固定结算与边界

```text
配方与装配 → 槽位 / ID / 类别 / 有限数值 / 操作数校验
  → 按四类核心固定顺序合成 → 只读方案 → 原子提交

直接命中 → 易伤放大 → 护甲平减至零 → 全局伤害倍率
  → 护盾吸收 → 生命损失 → 受击保护 / 应急治疗

燃烧 / 中毒 → 易伤放大 → 对应元素抗性 → 全局伤害倍率
  → 护盾吸收 → 生命损失 → 应急治疗
```

燃烧与中毒独立计时、可并存；同一状态重复施加只保留更强强度与较长剩余时长，不累加 DPS。持续伤害绕过平减护甲和短暂受击保护。减速抗性减少减速幅度；眩晕抗性在施加时缩短时长；易伤抗性仅减少额外倍率。多操作抗性按剩余伤害相乘合成，上限 95%。回复等待操作取更短值。

应急治疗仅在实际失去生命后触发：仍存活且生命不超过上限 30% 时，回复指定比例，进入独立冷却；不能复活。换装保留这项冷却。周期净化清除全部当前状态；换装保留其时钟。体力耗尽后恢复至上限的 25% 才能再次冲刺，避免耗尽后每帧反复启停。

状态、恢复及计时按最大 0.02 s 子步推进，每次 `Tick` 接受 0–10 s；无效数值不修改状态。直接攻击、状态、冲量的接口兼容 CustomLauncher，综合靶场复用现有池化弹丸和扫掠碰撞。装备本身不修改发射器配件或其输出属性。

## 结构与接入

| 目录 | 职责 |
| --- | --- |
| `Contracts` | 槽位、操作、属性值、只读方案、伤害报告 |
| `Definitions` | 装备配件、配方、目录、装配及装配快照 |
| `Compilation` | 校验、固定合成、诊断 |
| `Runtime` | 独立 `EquipmentState`、兼容伤害/状态/冲量协议的 `EquipmentHost` |
| `Samples` | 可嵌入的中文 `EquipmentWorkbenchUI` 与内容资产 |
| `Editor` | 内容制作与旧配方兼容迁移；旧 builder 仅保留内容路径工具 |
| `Tests` | 装配规则、状态结算与真实弹丸；综合场景测试位于 CombatRange |

把 `EquipmentHost` 添加到玩家碰撞体或其父对象，通过 `TryEquip(recipe.CreateLoadout())` 装配。失败会保留之前的方案、资源及装配。`Loadout` 返回装配快照；修改返回值不能绕过编译修改已提交装配。定义资源可在 Inspector 制作与维护，编译结果不再引用其可变操作数组。

现有角色移动控制器应读取 `host.State.MoveSpeed` 与 `host.ImpulseVelocity`，自行执行移动。设置 `AutoTick=false` 后，由现有角色主循环调用 `host.Tick(deltaTime, sprintRequested)`；默认 `AutoTick=true` 适合独立挂载。受击无需额外转接即可接收 CustomLauncher 的 `IDamageReceiver`、`IStatusReceiver`、`IImpulseReceiver` 调用。`Damaged` 事件提供直接伤害报告，供受击表现使用；持续伤害统计在 State 中。

装备 Runtime 仅依赖自身定义/编译和 CustomLauncher.Contracts；不依赖发射器执行、程序动画或寻路。CombatRange 集成层同时引用两个模块，提供可操控玩家测试体及共享能量适配；现有七种程序动画角色的移动输入映射仍由其调用方负责。

编辑器菜单 `CelToon/Combat Range` 提供 Open / Create or Rebuild / Validate Combat Range。重建综合场景保留已有配件与配方资产中的手工参数，目录重新收集内置条目。重建前需结束 Play、关闭综合靶场，并保存未命名场景。

旧 Range / Storage 场景及其专用材料已迁出 Assets，归档至 [legacy-range-storage.zip](../../../../Docs/CombatRange/Archive/legacy-range-storage.zip)。配件、配方、攻击配置及兼容核心保留，旧场景生成和预览入口已退役。

模块历史验证与迁移证据见 [CustomEquipment 验证记录](../../../../Docs/CustomEquipment/VALIDATION.md)，综合靶场验证见 [CombatRange 验证记录](../../../../Docs/CombatRange/VALIDATION.md)。当前使用基础几何外观与传统 Input/IMGUI；专用美术、音效、联网及存档不在此实现中。
