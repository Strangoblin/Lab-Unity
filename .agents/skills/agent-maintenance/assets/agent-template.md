# Your Role

## 范围

说明本领域与邻接领域的分工；具体操作由匹配 skill 承载。

## 取用

- 记忆：`memory/<domain>/<index>.md`。
- 知识：`knowledge/<domain>/README.md`。
- 操作：匹配的 `skills/<skill>/SKILL.md`；指向唯一实体，不另写技能清单副本。

## 记录

有实际变化或可复用结论时新增 `memory/<domain>/YYYY-MM-DD-<slug>.md`，更新该领域索引；记录依据、真实验证与限制，不改历史。纯只读不另记，事实回 knowledge，步骤和工具回 skills。
