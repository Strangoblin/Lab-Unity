# web-search — 联网搜索 + 方案设计

> 由 Experiment Mode 的 E1 阶段触发。

---

## 分支树

```
[E1] WebSearch → Plan
  │
  ├── 1. 搜索已有实现方案（论文、开源仓库、技术博客）
  │
  ├── 2. 找到可用的网络模板/参考代码
  │
  ├── 3. 验证可行性（API 兼容性、平台限制、依赖项）
  │
  └── 4. 输出 Plan：
        ├── 目标效果：最终要达成什么
        ├── 方案来源：URL + 为什么选这个方案
        ├── 技术路线：分几个阶段、每阶段做什么
        ├── 模板（如有）：找到的网络代码/仓库
        └── 预期结果：每阶段的验收标准
```

---

## OUTPUT 格式

```
## E1: WebSearch → Plan
Sources: <URL 列表>
Selected: <选中的方案 URL> — <选择原因>
Plan: <分阶段技术路线>
Expected: <每阶段验收标准>
```

## Red Flags

- 未找到任何网络方案 → 暂停，询问用户
- Plan 未包含来源 URL → 退回补充
