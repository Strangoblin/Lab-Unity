# 同类功能关联与复用

目标：同类功能沿用可解释的共同流程与接口，必要差异显式保留；整合同时处理重复算法，而不止合并文件与参数。
在方案设计、首次实现或宣称“无库内方案”前执行。适用于所有开发模式，不新增 MCP 门禁。

## 1. 找到关联实现

- 新增/扩展：从目标目录、最近的同类实现与相关库索引开始，读候选函数实现和实际调用点；选定可沿用的基线，说明需要偏离之处。
- 整合：读取全部待整合来源及其资源/参数绑定，不以搬入新目录视为完成。
- Shader/HLSL：先查 [HLSL 库索引与分工](../auto-manager/templates/shader/hlsl/README.md)，再用 `python3 .mcp/validation/project_resources.py path library.hlsl.shared` 解析库地址，读候选实源、合同注释及相关说明。
- 按计算机制检索，如网格/周期随机/TRS、采样核/半径换算，而不只按功能名。名字不同也可能实现相同流程。
- 无候选时，在相邻功能与相关库做一轮机制/同义词补查，然后说明未找到；不扫描全工程或默认搜索历史聊天。
- C#/Compute 同样沿类型索引寻找最近实现与共用模块，不套用 HLSL 的目录规则。

## 2. 对照流程与契约

先按数据流拆步骤，再对照实现；既看重复算子，也看多个算子串成的重复流程。
整合时在现有计划或任务说明写简短对照表；小变体只需记录与基线的差异，不另建文档。

| 阶段/候选实源 | 共同行为与契约 | 必要差异/历史差异 | 复用或提炼决定及依据 |
|---|---|---|---|

只检查影响本次决定的维度：

- 输入/输出、坐标空间、单位、aspect、源与目标尺寸、正逆变换。
- 随机 seed 的维度、通道/分布、时间单位、周期相位、生命周期与冻结。
- 参数来源、默认值/预设、0 的意义、资源与 sampler、宏/include/全局依赖。
- 采样核/权重、Alpha/色彩、合成顺序、tap/Pass/RT 成本与平台约束。

文件名、调用次数、函数签名和编译成功均不能证明契约相同。

## 3. 提炼与复用裁决

- 最终职责与行为契约相容 → 复用；仅调用上下文不同 → 最小适配；存在有依据的功能差异 → 保留并说明原因，避免靠大量分支硬塞进一个函数。
- 常数、公式结构或随机序列不同不构成保留变体的理由。按最终作用方式和作用范围裁决；随机需比较输出区间/分布、通道独立性、空间/时间相关性、精度与平台。仅实现不同且验证支持相同随机作用时，统一到已有算法；有具体表现或数据依赖时才保留必要差异。
- 同类公共流程 → 统一步骤与接口，参数承载可调差异，策略函数保留不同算法。先复用通用算子，再提炼项目内部流程。
- 按 [公共函数归属表](../auto-manager/templates/shader/hlsl/README.md#公共函数归属)区分项目公共与通用公共；前者留项目/功能族目录，只有后者可入通用库。被多处调用不是入库依据。
- 库缺失的能力需先说明通用契约、与已有函数的关系及受影响调用方；修改共享 API 时检查其消费者，不为一个效果扩大整库。
- 结构抽取默认保留原行为。随机分布、默认值、权重或输出变化须列为行为变化；任务已要求/接受类似随机效果时，可以统一算法并改变序列，不能仅因逐值不等就否决；未获此授权时将统一行为作为待选方案。
- 找到可复用函数不授权修改它；需要跨工作目录写入时沿用现有工作区流程。复用可只增加调用，项目流程不必移入库。

## 4. 用行为验证决定

按实际变化选少量有区分力的验证，复用现有验证入口，不给纯格式改动追加测试：

- 等价抽取：固定输入、时间/seed、预设与分辨率，对照抽取前基线并给容差。
- 有意统一行为：对照明确的新期望，覆盖受影响变体，不声称旧输出等价。随机在实际输入域核验范围、偏置、通道和相邻/跨帧相关性；涉及表现的差异补代表场景对照，统计相似本身不能证明画面相同。
- UV/TRS 用非方形视口/网格；随机用固定 seed 与周期边界；采样用常量/脉冲、实际尺寸与权重归一化；API 改动检查消费者。
- 编译/有限值检查只支持其实际结论；无法运行行为验证时标记未验证并给最小验证方法，不能将计划写成通过。

## 留下下次可发现的关联

只读/规划任务在回复或现有计划记录关联；实施任务在已有功能 README 或库索引/合同注释记录沿用的实源/通用函数、项目公共入口、保留差异与验证结果，写入范围沿用任务授权。
不复制算法正文或新建通用清单；后续同类实现从这一关联基线继续，库索引失效时以实源为准。

项目已有的 Hash 迁移/消费合同验证器是项目专属内容，按资源绑定 `validation.hash.guide` 取用（`python3 .mcp/validation/project_resources.py path validation.hash.guide`）；只在该项目合同适用时取用，不当作任意随机算法的通用检验器。
