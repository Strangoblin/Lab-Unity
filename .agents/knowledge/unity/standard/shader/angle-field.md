# 多中心角场（圆周值场）

> 角场 = 每像素输出一个方向或相位（漩涡、极坐标图案、径向条纹）。单中心天然连续，多中心必断。
> 实例：`Assets/Mine/Shaders/Render/VanGogh/TheStarryNight.shader`（Voronoi + 2NN）。

---

## 拓扑约束：N 个中心必然断裂

带 2+ 中心的标量角场一定存在鞍点（指数定理：N 源 → 至少 N−1 个）。鞍点处方向无定义，
所以「多中心融合成一个角度」躲不掉断裂 —— 能选的只有断在哪里、以及断得多明显。

## 连续性配方

1. **场必须是圆周值**：用单位向量求和，不要在 `[0,1]` 区间上取 max —— 区间值把圆降级成线段，
   每个源的回绕处都会撕裂。
2. **消费侧必须周期化**：`cos/sin`、`frac`、整数倍切分。这样 `atan2` 的 −π/+π 切缝不可见。
3. 单中心场无鞍点，天然连续（移植版 `TheStarryNightPort.hlsl` 即此）。

同理，**径向 SDF 不存在融合问题**：`min()` 于连续函数仍连续。融合只属于角场。

## 四种融合方案

| 方案 | 组合方式 | 断裂位置 | 取舍 |
|---|---|---|---|
| 区间 max | `[0,1]` 值取最大 | 每个源的 −X 回绕处 | ✗ 弃用 |
| 圆均值 | 单位向量求和 → `atan2` | 两源连线（和→0 的鞍点），可用 lerp 收敛掩蔽 | 星少时够用 |
| **Voronoi + 2NN（现用）** | 最近 + 次近源，边界带内单位向量圆插值 | 每对源之间退化为单点 | N 星通用，O(N) 距离成本 |
| 模式级混合 | 每源独立单中心图案 + 距离衰减混合**输出** | 无（组合发生在输出层） | 最稳，代价 N 倍图案计算 |

Voronoi + 2NN 的写法：记录最近 `d1 / uA` 与次近 `d2 / uB`，边界带半宽 `_AngleBlend`
（UV 单位，默认 0.08）：

```hlsl
float t = saturate(0.5 + 0.5 * (d1 - d2) / band);
float3 v = normalize(uA * (1.0 - t) + uB * t);
float angle = atan2(v.y, v.x);
```

远离边界退化为纯最近源，单源自动退化；成本只多一次距离比较与一次加权。

## 调试：色轮可视化

`0.5 + 0.5 * cos(angle + float3(0, 2.094, 4.189))` —— cos 为偶函数，−π/+π 同色，
连续性一眼可见；断裂处会出现硬色边。

## 尺寸对齐

`lerp(float3, float4, float)` 这类混合尺寸会在 Metal 触发隐式截断警告，用 `.rgb` 显式对齐。
