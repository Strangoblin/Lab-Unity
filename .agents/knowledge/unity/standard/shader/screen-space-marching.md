# 屏幕空间步进的坐标系盲区

> 同一根射线在 DDA 与 Ray3D 两种步进下的失效区互补。选错不是精度问题，是画面级畸变。
> 来源：SSR 反射的鱼眼扭曲（2026-08-07；该实现已退役，结论适用于任何屏幕空间追踪）。

---

## 症状

DDA 模式在近距离出现鱼眼：外圈正常、中圈黑色真空环、内圈环形反向映射。Ray3D 无此问题。

## 根因：齐次插值的 w 过零

透视投影 `UV = clip.xy / clip.w * 0.5 + 0.5`。射线端点 `endCS.w` 在反射方向指向或背离相机时
趋近零或变负：

- **DDA** 把 `w` 当线性插值量（等价于插值 `K = 1/w`）。`w → 0` 时 `K → ±∞`，步长爆炸、深度比较失效。
  更隐蔽的是 `endCS.w < 0` 时负负得正，`endS` 仍落在 `[0,1]` —— 两端都在屏幕内，中间穿过了奇异点，
  所以边界检查拦不住。
- **Ray3D** 在世界空间步进，每步独立投影；`clip.w` 变号时 `S` 自动跳出 `[0,1]` 触发 `break`，
  天然受保护。

## 判据：按 w 比值切换

DDA 在屏幕中心暴露（鱼眼），Ray3D 在边角暴露（越界丢步）。修不好任何一种，只能混合：
`endCS.w / startCS.w` 比值安全时走 DDA，危险时回退 Ray3D。

推广的说法：**屏幕空间算法要检查自己的插值量在视锥内是否有定义域外**——`1/w`、`1/z`、
屏幕 UV 都是这类量；插值安全不等于中间路径合法。
