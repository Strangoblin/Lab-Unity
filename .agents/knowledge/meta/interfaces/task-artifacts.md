# 会话产物与测试生命周期

本契约是 Claude / Codex / Unity 工作流的共同落点规范。只有任务产生文件时才创建工作目录；延续同一任务时复用已建的规范会话目录。路径相对于仓库根，运行编号须避免并发覆盖。

## 临时落点

统一使用 `tmp/sessions/<YYYY-MM-DD>-<task-slug>-<unique-id>/`：

| 子目录 | 内容 | 收尾 |
|---|---|---|
| `staging/` | 一次性脚本、待应用源码/文档、计划草稿 | 应用后判断是否仍需复现，不作为长期源 |
| `fixtures/` | 合成输入、必要旧式基线、隔离测试项目 | 可重建项目副本随运行结束清理；失败可保留并报告路径 |
| `output/` | 编译产物、日志、截图、回读数据、工具报告 | 不进 Git；可重建者清理，必要证据进入归档候选 |
| `evidence/` | 已挑选的结果、比较说明、待长期保留的证据 | 写明用途/所有者/依赖/清理条件后按下表归档 |

在已有计划或结果说明记录任务状态及产物用途即可，不为纯对话创建目录、空 manifest 或 README。工具内部短寿命文件允许 OS `mktemp`，必须唯一命名并用 `finally` / trap 收尾；跨会话证据不得只留在系统临时目录。

## 长期归属

| 内容 | 权威落点 |
|---|---|
| 功能代码、配置和说明 | 原功能目录；`Assets/Mine` 写/删/移仍走 Unity 门禁 |
| 功能专属、可复现验证源码与必要基线 | 同功能 `Validation~/`，由 README / VALIDATION 给出入口；新运行输出回任务目录 |
| skill 的复用脚本或验证工具 | `.agents/skills/<skill>/scripts/`；模板归该技能 templates/assets；由技能索引注明用途、依赖和运行入口。项目专属验证器不进共享库，归项目功能 `Validation~/`，经[项目资源](project-resources.md)绑定按 ID 取用 |
| 平台/MCP 契约测试源码 | 原平台 `tests/`；MCP 默认使用隔离 runner，不在生产项目 reset |
| 诊断结论与必要历史证据 | `.agents/memory/<domain>/` dated 记录；证据可放同库 `evidence/<date-task>/` 并链接，避免整包工作区 |
| 真正的功能历史资产（场景等） | 功能所属 `Validation~/Archive/`，保留 GUID/来源/用途；不能混为运行资源 |

归档测试必须同时保留不可重建的基线/输入，修正路径和依赖后实际复跑；不要只搬报告、留下不可执行脚本。仅名字含 test、未被场景引用或文件较旧，都不足以判无用。

## 关闭与清理

1. 区分保留源码、归档证据、可重建输出、唯一回退点和运行状态；只处理本任务授权范围。
2. 删除/移动存量文件先列精确路径、用途、引用、Git 状态和归档目标，遵循根 AGENTS.md 的人工确认；已有明确授权不重复请求。执行前复核内容未变化，dirty/唯一副本先保留或归档。
3. 新建的专属测试 fixture 明确由 runner 管理，随运行用 `finally` 清理，不波及其他任务目录；失败现场注明保留理由。MCP 的生产 state/审计与 Unity/Python 依赖缓存不是测试垃圾。
4. 结论写入角色 memory，保留入口与必要证据后再清理中间输出；不能按扩展名扫掉整个 `tmp/`。

回退遵循项目既有 Git 偏好：记录精确文件和基准，不新建资产内 `.backup_*` 或压缩回退包，不对整个脏工作区自动 stash/add/commit。验证输入快照只为复现，不替代版本管理。

## 遗留与扫描边界

- `.codex/tmp/`、`tmp/` 散文件、`tmp/.reusable/`、`Screenshots/` 和资产内 `.backup_*` 属遗留；停止新增，按精确清单迁移/清理，不能整目录视为垃圾。
- 续接遗留任务时，新产物进入关联的 `tmp/sessions/`，注明旧基线位置；保留原件，存量迁移仍走确认清单。
- 既有 `.codex/tests/<suite>/output/` / `run.log` 是登记的可重建工具输出；保持接口兼容，定期评估。新工具优先允许 `--task-dir` / 输出目录注入。
- 架构扫描只认仓库根下真实共享/平台层，排除会话目录、隔离项目、缓存与工具输出；保留 `.codex/tmp/README.md` 的薄路由检查。临时嵌套 `.agents/.mcp` 不能冒充真实层。
- 平台配置、`.mcp/state.json` / 审计日志、`.unityctl` 活跃状态、Library/Temp/IDE 工程文件按各工具职责保留；不为目录整洁删除环境或未知资产。
