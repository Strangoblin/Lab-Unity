# Parameter Panel — 面板参数分层

> 函数无关层：RendererFeature 的 `Settings`、MonoBehaviour、VolumeComponent 的面板一律适用。
> 代码骨架：[templates/standard/script/parameter-panel.cs](../../../templates/standard/script/parameter-panel.cs)
> 来源：2026-09-20 PCSS 参数整理 → [memory](../../../memory/2026-09-20-parameter-layering.md)

## 判据 — 两个正交问题

「这个参数属于技术还是美术」是伪二分。决定暴露形式的是另外两个问题：

1. **成本占比** —— 它对帧率的影响是否压倒性？
2. **是否需要微调** —— 合理取值是连续区间，还是有限几组固定组合？

两个都答「是」→ **不该逐个暴露**，划档位。给 8 个整数滑条，用户组合出的多数取值
要么性能崩、要么画质崩；给 3 个档位，每档都是已知良态。**暴露形式本身就是信息。**

## 三层 + Debug

| 组 | 判定标准 | 改它的理由 | 暴露形式 | Header 名 |
|---|---|---|---|---|
| Technical | 几何、投影、深度偏移 | 正确性（漏光/痤疮/覆盖） | 连续可调 + `[Range]` | `Technical · <子域>` |
| Performance | 纯成本，不需要微调 | 帧率 | **档位（枚举）** | `Performance` |
| Artistic | 每个参数对应一个观感维度 | 画面好看与否 | 连续可调 | `Artistic` |
| Debug | 中间结果可视化 | 排障 | 枚举 / 布尔 | `Debug` |

`Debug` 与前三组**正交**：它不调效果，只改「显示什么」。每个 Feature 必须有一个。

## 规则

**① 实现细节不进面板，内化为 shader 常量。**
时域钳制半径、置信度幂次、PCF 偏移乘数这类「调了只会更糟」的量，写成 HLSL 顶部
`#define`。省下的不只是面板格子，还有配套的 `PropertyToID` 与每次 `SetCompute*Param`
（PCSS 先例：4 个常量合并了 5 个 uniform + 5 个 nameID + 5 次绑定）。

**② 开关类参数一律「0 = 关闭」**，不用 `bool enabled` + `float strength` 两个字段。
强度为 0 时开关本就无意义 —— 合并后省一个字段，且语义只剩一种。

**③ 档位表用纯函数展开，不在 pass 间传可变状态。**
多个 pass 需要同一份档位结果时，各自调用同一个 `GetTier(performance)` 重新展开，
而不是把某一侧的私有字段提升为共享状态。纯函数无状态 ⇒ 不存在不同步的可能。

**④ 默认档必须逐字段复现整理前的资产值。** 默认行为不变是这类重构唯一的安全保证。

**⑤ 同源的量放同一档。** 一档应同时决定所有同源的尺寸 / 数量，否则档位名会骗人
（「High」只提分辨率、不提采样数）。但**决定「分布方式」而非总成本的量不进档位**
（如 PSSM 的 `pssmLambda`）—— 「同源」不等于「都该进档位」。

**⑥ 空间滤波把预算与感受野分开。** Blur、SNN、Kuwahara、双边滤波和屏幕空间
Resolve 的采样数/分布/下采样率归 `Performance` 质量档；半径归 `Artistic`，只缩放
固定 offset，不得进入循环边界。统一实现与验收见
[spatial-filter-budget.md](../../shader/postprocess/spatial-filter-budget.md)。

## 档位化前置检查 — 参数半接线

把尺寸类参数升格为档位前，先确认它**两侧都接线**：

> **grep 数值字面量，不要 grep 参数名。**

参数名只会在 C# 侧命中，看着完全正常；真相在 shader 里那些本该是 uniform 的硬编码
字面量上。判据 = `grep <参数名>` 与 `grep <该参数默认值>` 得到的文件集合，
**差集里若出现消费方文件，就是半接线**。

默认档下两侧数值恰好一致，所以缺陷长期不可见；**一旦升格为档位就从「潜在」变「必现」**，
且错乱的原因离参数十万八千里。修法是让该参数成为**唯一来源**，两边都从它推导
（尺寸类打包成 `float4 (size, 1/size, …)`，沿用工程既有的 `_ScreenSize` 惯例）。

> ⚠️ 排除项：`1.0 / 4096.0` 这类看着像分辨率的量，可能是**深度域** epsilon。
> 参数化前必须确认每个字面量的语义域，不能按数值匹配。
