# Standard Script Templates

Function-independent Script documentation and code templates.

| Template | Purpose |
|---|---|
| [standard-script.cs](standard-script.cs) | General C# Script skeleton — static utility + MonoBehaviour dual forms (compilable) |
| [parameter-panel.cs](parameter-panel.cs) | Inspector panel skeleton — Technical / Performance / Artistic / Debug layering + tier table (compilable) |
| [script-doc-template.md](script-doc-template.md) | General C# Script technical documentation (mirrors the Shader doc template) |

Structure conventions for writing the scripts themselves: `references/standard/script/script-structure.md`.
Responsibility skeletons (Baker / Generator / Manager / Controller / Window) live under `templates/script/`.
