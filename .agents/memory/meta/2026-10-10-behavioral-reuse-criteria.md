# 按最终作用裁决复用

用户补充：常数或结构不同、功能相同的 Hash，需要根据最终作用方式与作用范围决定是否合并；随机效果类似时可以统一，参照 Sandy / Rainy / Snowy 的整合。

对 [unity-feature-reuse](../../../skills/unity-feature-reuse/SKILL.md) 作窄范围修正：取消“算法不同即保留”的自动裁决，改为按最终职责与行为合同判断。结构抽取仍默认保持行为；任务接受类似随机效果时允许改变序列，并明确记录该变化。

随机候选的判断包括范围、分布、通道及空间/时间相关性、精度与平台；不能只凭常数、签名或逐值不等保留变体。统计相似也不能单独证明画面相同；必要表现差异需具体证据。项目公共与通用公共的归属规则保持原权威入口。

P1–P3：只更新现有 skill 的裁决与验证条目，不增加算法正文、脚本、目录或门禁；两平台沿用共享源软链。项目应用与验证结果由 Unity 领域记录，见 [Hash 提炼记录](../../unity-developer/memory/2026-10-10-hash-function-extraction.md)。

框架验收：隔离项目运行 MCP 配方与知识路径两套测试通过，真实门禁 state 与审计日志未变；共享架构 strict 检查通过。未修改 `.mcp` 判定或 policy；摩擦报告的 `norm.region-added` / `placement.root.new` 退役候选留待专项复核，不据零命中自动降级。
