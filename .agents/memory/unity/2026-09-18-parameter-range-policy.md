# 用户约定

Shader 效果参数为 0/1 等端点导致的除零、退化区间等问题，后续通过参数入口统一钳制合法范围处理，不在每个计算点重复添加 epsilon、max、clamp 或条件分支，以保持原型简洁和可维护性。

- 本次只记录策略，不宣称统一钳制已实现；不要顺手逐点修复端点问题。
- 后续集中处理时根据各参数的数学定义确定范围，覆盖材质与脚本赋值入口，不把所有参数机械限制到同一区间。
- 此约定针对可控效果参数的范围；不等同于删除共享数学库既有保护，也不替代运行时资源与相机状态检查。

# 本次应用

Snowy 的场景风效复用 AtmosphereTex.r，在等比屏幕坐标中横向滚动、Repeat 采样，并按背景深度加权与雾合并。参数入口范围处理另行完成，保留既有 Wind=1 雾距离为零及 Frost=0 退化 smoothstep 的待办。
