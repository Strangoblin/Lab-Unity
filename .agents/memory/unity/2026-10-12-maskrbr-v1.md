# MaskRBR 首版

用户批准从 SSL 分离径向效果，并明确天空和指定物体产生光束／拖尾，允许扩散到原轮廓之外。实现入口和接入步骤见 [MaskRBR README](../../../../Assets/Mine/Shaders/PostProcess/MaskRBR/README.md)。本任务未修改 SSL、MaskBlur、PBRToon、共享 HLSL、现有 Renderer 或场景资产；既有脏改动保留。Git 起点 `f9b3ad8`，本轮未提交。

## 实现与边界

- 新建 `MaskRBRFeature.cs`、`MaskRBR.shader`、`MaskRBRMask.shader`。在 AfterRenderingSkybox 调度可见物体遮罩 → 天空／物体联合遮罩 → HDR 预乘提取 → 归一化径向采样 → 加法合成；透明物随后正常渲染。
- Sky / Objects / SkyAndObjects 为源选择；指定物体采用 GameObject Layer 与 Renderer opaqueLayerMask 交集，通过覆盖材质和场景深度选取可见实体。源遮罩只限制发光来源，合成不再乘源遮罩，光束可覆盖其他不透明前景。
- 第一版不复制原材质 alpha clipping、自定义顶点位移或特殊剔除，不支持透明 source；不实现体积光或接收面的三维遮挡。需要这些能力时扩展原材质 Mask Pass／独立 receiver 策略。
- HDR 采用 RGBA16F；RGBA 同一套固定 tap／权重位置，除以核权重和，不除以滤波 alpha。越界采样贡献零但保留分母；最终 `scene.rgb + rays.rgb × intensity`，保留 scene alpha。修正旧 SSL 径向核的隐式增益；加法仍会增加亮度。
- Low / Medium / High = 16 / 24 / 48 taps；Low 宽高各 1/2，并在四点下采样前逐 tap 预乘。Length 以最终输出高度为单位，独立于质量预算，不越过焦点。抖动复用 HashFunction，空间稳定、无时间种子。
- MainLight 使用方向投影、当前相机矩阵／投影约定，不人为指定光源距离或固定 Y 翻转；无主光、背向主光、正交 MainLight 输出零光束。Manual 支持自由 UV 焦点和正交相机。
- Debug = Mask / Source / Rays；Off 时 intensity=0 或 length=0 跳过效果。重复 Create / Dispose 管理两份运行时材质。未持久接入现有 Renderer；两个 Shader 需按 README 显式绑定。

## 验证

Unity 6000.3.14f1、URP 17、Metal / Apple M2。C# 编译通过，实际 GPU 变体执行后两个 Shader supported=true，Pass 数 4 / 1，ShaderUtil 消息均为零；最终错误日志为空。五份 C#／Shader 源码各自通过结构规范检查。

验证源码归档到功能 `Validation~/`，Unity 不自动导入。归档后的入口实际复跑：

- [GPU 报告](evidence/2026-10-12-maskrbr-v1/shader-results.json)：56/56 通过，0 失败，全局状态恢复。线性 float 输入与回读，实际 half 输出；逐通道容差 `0.002 × (1 + |expected|)`，所有 RGBA 像素有限。覆盖 HDR 常量归一化、源联合与空源、阈值、预乘下采样、稳定抖动、主光／Manual、非居中投影、越界零贡献、宽屏／竖屏跨度与 alpha；包含独立颜色／遮罩平均、Clamp 边缘和 Y 镜像负控。
- [隔离管线报告](evidence/2026-10-12-maskrbr-v1/pipeline-results.json)：20/20 通过，0 失败／渲染错误，23 次 SingleCameraRequest 对应 23 次相机回调。使用临时 PC_Renderer／URP 副本、预览场景与实体网格；验证被完全遮挡的选中物体、未选物体排除、天空联合、三档轮廓外拖尾、合成、参数端点、主光投影与正交 Manual。renderScale=0.5 仍绑定最终输出 640×360。pipelineRestored / activeSceneUnchanged / originalRendererUnchanged 均 true。
- 运行时材质生命周期：Create 四次后 Dispose / Destroy，目标 Shader 的 Material 数量从 0 回到 0。
- 图像为完整 640×360，HDR 显示映射 `c/(1+c)` 后转 sRGB；只作形态证据，不用于 HDR 数值判断：[物体遮罩](evidence/2026-10-12-maskrbr-v1/object-mask.png)、[光束](evidence/2026-10-12-maskrbr-v1/object-rays.png)、[合成](evidence/2026-10-12-maskrbr-v1/object-composite.png)。可见红色来源向外形成拖尾，蓝色未选物体不参与发光。

GPU fixture 曾因 CommandBuffer 投影绑定次序与边界探针未实际越界失败；修正验证输入后通过，生产公式未因此修改。投影对照使用独立 GL.GetGPUProjectionMatrix 推导，含非居中焦点和 Y 镜像负控。

现有场景多个 Feature 的顺序组合、XR、动态分辨率、全部 MSAA 组合和 GPU 耗时尚未覆盖。SingleCameraRequest 会抑制 RenderGraph Debug 数据，因此不声明实测资源预算。目标场景观感待用户调参。
