# MaskBlur 分层采样暗点与两轮 H/V

接续 [RimToon 退役记录](2026-10-08-rimtoon-maskblur-pbrtoon.md)。用户已确认 Low 第二轮显著改善颗粒，并要求记录暗点原因、将 Medium 也改为两轮 H/V。

## 已实施的路径

- `Assets/Mine/Special/HLSL/BlurFunction.hlsl` 提供输出像素 / 输出高度归一化的 `Blur_GetUVStep`，以及固定核、分层抖动核；旧 Gaussian / Bilateral 接口保留原语义。
- 抖动使用输出像素坐标、Pass 种子、tap 编号生成的稳定 uint hash，不引用时间。各层独立扰动，但并非蓝噪声。
- Low 在半分辨率 Extract 中四点采样，每点先构造 `(scene.rgb × mask, mask)`，再 float 累加平均。避免背景颜色与平均遮罩相乘的污染，以及 HDR 半精度中间累加溢出。
- 当前所有档位固定两轮 H/V，每轮步长 `requestedRadius / sqrt(2)`，H/V 种子为 0、1、2、3。Radius 不参与采样预算或循环边界；Radius=0 跳过滤波并使用全分辨率提取。

| 档位 | 工作分辨率 | 抖动核 / 滤波读取数（每工作像素） | 固定核 / 滤波读取数 |
| --- | --- | --- | --- |
| Low | 1/2 宽高 | 每方向 5 tap × 两轮 / 20 | 每方向 5 tap × 两轮 / 20 |
| Medium | 全分辨率 | 每方向 9 tap × 两轮 / 36 | 每方向 5 tap × 两轮 / 20 |
| High | 全分辨率 | 每方向 9 tap × 两轮 / 36 | 每方向 5 tap × 两轮 / 20 |

各档完整路径为 7 个逻辑 RT，物理复用由 RenderGraph 管理。当前 Medium 与 High 配置相同，保留枚举以兼容序列化设置；尚未测量 GPU 耗时。Shader / HLSL 无需为 Medium 的第二轮修改，调度由 Feature 负责。

## 暗点原因与边界

当前算法是等宽层内均匀选点，再乘固定 Gaussian 近似层质量，期望对应分段常量核；不是按 Gaussian 累计概率做重要性采样。固定层权重与层内均匀分布相匹配，并不存在漏除 PDF 的归一化错误。

九采样中心层质量约 0.16303，邻层约 0.15222，中心层权重并不占主导，而且中心样本会移动。单方向步长 18 时中心层最大位移约 4.98 像素；H/V 中心层路径的权重乘积约 0.02658。这不是整个二维中心像素的权重，也不是最终像素值。

输入是 `scene.rgb × mask`，小物体、硬轮廓或大半径下，许多采样落在零覆盖区；有限采样的命中起伏足以形成相对暗点，极小覆盖区甚至可能完全漏采。每像素、每层 hash 不同可以打散规则伪影，但不能保证低方差。整段支持域都处于真正恒定颜色 / 遮罩内时，归一化核应保持常量，不能把这种区域里的实际零值一概归因随机采样。

## GPU 控制与匹配参考

通过实际 MaskBlur H/V Shader Pass 过滤纯红硬圆：640×360、线性输入，RGBA16F 中间纹理、RGBAFloat 回读；圆内 red=alpha=1，圆外为 0。共六项控制通过，纯红圆 red 与 alpha 全图最大差均为 0。

| 输入 / 滤波 | 圆心附近线性红通道 | 观察 |
| --- | --- | --- |
| 全画面恒定 RGBA / 一轮九采样 | 全图恒定，仅半精度存储舍入 | 没有空间噪点 |
| 半径 80 圆 / 一轮九采样 | 1–1 | 支持域完全覆盖时保持纯色 |
| 半径 16 圆 / 一轮九采样 | 0.09448–0.26758 | 起伏显著，中心附近没有实际 0 |
| 半径 16 圆 / 两轮九采样 | 0.21252–0.23315 | 起伏显著下降 |
| 半径 3 圆 / 一轮九采样 | 0–0.02667 | 原圆 32 个像素中 50% 为精确 0，圆心也为 0 |
| 半径 16 圆 / 一轮五采样 | 0.08441–0.36572 | 更低预算亦能产生明显覆盖起伏 |

半径 16 案例统计圆心半径 4 的区域；半径 3 案例统计整个原圆。密集参考积分当前分段核及双线性重建，假设各层理想均匀、独立，未包含 hash 相关性与半精度舍入。半径 16 的一轮参考 / GPU 均值为 0.19677 / 0.19538，两轮为 0.22169 / 0.22176；相对各自参考的局部 RMS 为 17.15% / 2.53%。两轮匹配期望二阶矩，但核形状及中心均值会变化，不能描述为完全相同核的纯降噪。

实际 PBRToon 单轮 Medium 截图的严格遮罩内部没有 RGB 全 0 或近 0 像素；远球中心 7×7 PNG 红通道为 91–127，是相对暗点。PNG 裁切无法证明 HDR 源红通道恒定。Blur Debug 显示独立柔光；正式合成在该 Feature 阶段为 `scene.rgb + blur.rgb × intensity`，非负柔光不会把原场景正红色变成黑色。
