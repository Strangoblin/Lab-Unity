# Rainy — 屏幕雨滴与雨天气氛

Shader：`PostProcess/Rainy`。沿用 Snowy 的两段全屏 Pass、周期随机数、TRS 面片、SDF 粒子权重、三次气氛噪声采样与冷调色。

## Pass 0：雨滴折射

屏幕分为 6×4 格，每格运行一个独立的 Snowy 式周期粒子。不同格使用不同随机序列与周期相位；每个像素只计算所属格，所以不需要在全屏对 24 个雨滴逐一采样。单滴尺寸按格子调整，使画面上的滴径接近原 Snowy 单粒子。雨滴接近周期末尾会淡出，因此同一时刻可见数量少于 24。

`_RainTex.r` 与原 SDF、淡出权重合成雨滴的凹陷深度场。中心及上下左右各取一次深度，以局部高度差求坡度，再按雨滴角度旋转。深度从中心向边缘变浅，梯度指向凹陷中心，直接作为屏幕 UV 折射偏移；纹理上的高度起伏会改变坡度。邻域间隔固定为雨滴局部 UV 的 0.02，最大 UV 偏移由 `0.015` 固定系数限制。高度场另乘局部半径 0.30–0.45 的圆形渐隐，确保贴图扰动不会把折射延伸成格子轮廓。

## Pass 1：水雾与高度雾

保持 Snowy 的 7 倍、5 倍及滚动噪声采样和最终冷调色。原霜边白化改为五点小半径水雾模糊，画面中央保留较弱水雾。场景雾保留原深度与滚动噪声项，再乘视线中点的世界高度衰减；雾基准为世界 Y=0。

## 参数

| 参数 | Shader 默认值 | 作用 |
|---|---:|---|
| Rain Tex | white | 高度图 R 通道；示例材质绑定 Noise2DRG |
| Randomness | 0.5 | 粒子落点、角度、尺寸随机幅度 |
| Coldness | 0.3 | 与 Snowy 相同的冷调色强度 |
| Foggy | 0.5 | 粒子、水雾、场景雾强度 |
| Wind | 0.5 | 粒子周期与气氛噪声滚动 |

示例材质沿用 Snowy 示例数值：Randomness=1、Coldness=1、Foggy=0.3、Wind=0.5。

## 使用

在 PC_Renderer 的 DebugOutputFeature 中绑定示例材质，开启 Active、Debug、Require Depth，并将 Additional Pass Index 设为 1，按顺序执行两个 Pass。-1 只执行雨滴 Pass。

当前是屏幕空间凹陷折射，不模拟真实玻璃厚度。格子边界限制每滴的最大运动范围，画面质量需在目标场景中观察。大半径水雾失焦需要额外的降采样模糊链；现有五点核主要提供轻微朦胧。
